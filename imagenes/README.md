# Imágenes de la página

Coloca aquí los archivos de imagen que quieras servir junto con la página.
Con el servidor local de desarrollo, una imagen llamada `obra.jpg` estará
disponible en `http://localhost:8000/imagenes/obra.jpg`.

Para mostrarla en la galería, activa el modo administrador en la página, elige
**Subir Nueva Imagen** y pega esa URL. La galería guarda la referencia en el
almacenamiento local del navegador; copiar el archivo a esta carpeta por sí solo
no lo añade a la galería.
