# market

## Visualizar la página

Abre `estructura_principal.html` en un navegador moderno. La página no requiere
compilación ni instalación de paquetes. Tailwind CSS, Lucide y las fuentes se
cargan desde CDN, por lo que se necesita conexión a internet para esos recursos.

El contenido de ejemplo y las publicaciones hechas desde el modo administrador
se guardan en el almacenamiento local del navegador; no se suben a la nube.
